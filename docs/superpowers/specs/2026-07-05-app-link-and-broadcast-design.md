# Дизайн: кнопка застосунку Nutriday + механізм розсилки

- **Дата:** 2026-07-05
- **Статус:** Затверджено (готово до планування реалізації)
- **Стек:** NestJS · node-telegram-bot-api · MongoDB/Mongoose · OpenAI

## 1. Контекст

Існує повноцінний веб-застосунок Nutriday (`nutriday.com.ua`) з розширеним функціоналом:
меню на тиждень, заміна окремої страви, список покупок, підрахунок БЖВ. Потрібно:

1. Додати в Telegram-бот кнопку-посилання на застосунок.
2. Побудувати багаторазовий механізм розсилки повідомлень користувачам бота, щоб
   повідомити про новий сервіс і його розширений функціонал.

У системі ~2000 користувачів, більшість неактивні. Розсилка — це насамперед
кампанія, тож таргетинг і обробка заблокованих критичні.

## 2. Цілі

- Inline URL-кнопка на застосунок у кількох точках бота.
- Багаторазова адмін-команда `/broadcast` (текст або фото + кнопка застосунку).
- Тротлінг, обробка помилок Telegram, позначка заблокованих користувачів, звіт адміну.
- Розсилка лише активним користувачам.

## 3. Non-goals (YAGNI)

- Персистентна/відновлювана черга розсилки.
- Лог доставки по кожному користувачу.
- Планувальник розсилок, A/B, аналітика поза UTM.
- Тригер розсилки через REST API / адмін-панель.

## 4. Ключові рішення (підтверджені)

| Питання | Рішення |
|---|---|
| Тип кнопки | Звичайна inline URL-кнопка (не web_app) |
| Місця кнопки | Reply-клавіатура, після видачі меню, `/start` + `ℹ️ Допомога` |
| Запуск розсилки | Адмін-команда `/broadcast` у боті (обмежена `ADMIN_CHAT_ID`) |
| Вміст розсилки | Багаторазовий: текст або фото + підпис; кнопка застосунку додається завжди |
| Обробка доставки | Тротлінг ~25/с, обробка 429, позначка заблокованих у БД, фінальний звіт |
| Аудиторія | Лише активні: `amountMenu > 0` та `isBlocked !== true` |
| Формат тексту | Простий текст (без Markdown), щоб уникнути помилок парсингу |

## 5. Фіча A — Кнопка застосунку

### 5.1 Спільний хелпер
Новий `src/utils/appButton.ts` повертає inline-клавіатуру з однією URL-кнопкою
`🥗 Відкрити Nutriday`. Хелпер параметризований варіантом URL:
`appButton('cta' | 'invite')` — точки в боті (меню, start, help, reply-клавіатура)
використовують `cta`; розсилка використовує `invite`.

### 5.2 URL-и (в config/constants)
- **CTA-кнопка:** `https://nutriday.com.ua/?utm_source=telegram&utm_medium=referral&utm_campaign=miniapp&utm_content=cta-button`
- **Запрошення (розсилка/текст):** `https://nutriday.com.ua/?utm_source=telegram&utm_medium=referral&utm_campaign=miniapp`

Кнопки в боті використовують CTA-URL; розсилка (запрошення) — URL запрошення.

### 5.3 Точки показу
- **Reply-клавіатура:** до `mainKeyboard` додається другий ряд `[🥗 Застосунок]`.
  Reply-кнопка не може тримати URL, тож її натискання ловиться в обробнику
  `message` → бот надсилає коротке промо-повідомлення з inline URL-кнопкою.
- **Після `/menu`:** inline-кнопка прикріплюється до відредагованого повідомлення з
  меню (`reply_markup` в `editMessageText`) з підводкою про розширений функціонал.
- **`/start` і `ℹ️ Допомога`:** inline URL-кнопка окремим коротким повідомленням
  (reply-клавіатуру й inline-кнопку не можна поєднати в одному повідомленні).

## 6. Фіча B — Механізм розсилки

### 6.1 Зміна моделі даних (`User` schema)
- `isBlocked: boolean` (default `false`) — `true`, коли надсилання повертає 403.
- `blockedAt?: Date` — час позначки (опційно).
- При `/start` `isBlocked` скидається в `false` (користувач повернувся).

### 6.2 Визначення аудиторії
«Активний» = `amountMenu > 0` **та** `isBlocked !== true`. Метод у `UserService`,
напр. `findActiveForBroadcast()` (і/або `countActiveForBroadcast()`).

### 6.3 `BroadcastService` (модуль telegram)
Новий сервіс, що інкапсулює весь потік розсилки. Відповідальності:

- Тримає чернетку розсилки та стан адмін-діалогу (in-memory; фактично один адмін).
- `start(chatId)` — стартує потік, лише якщо `chatId === ADMIN_CHAT_ID`.
- Захоплення контенту: приймає текст **або** фото з підписом; зберігає чернетку
  `{ text?, photoFileId?, caption? }`.
- Прев'ю: показує адміну повідомлення точно як його побачать користувачі (з кнопкою
  застосунку) + рядок «Надіслати N активним користувачам?» та inline-кнопки
  `✅ Підтвердити` / `❌ Скасувати`. `N` = кількість активних.
- Підтвердження: ack «Розсилку почато», `runBroadcast()` запускається у фоні
  (не awaited, щоб не блокувати бота).
- `runBroadcast()`: вибирає активних, ітерує з тротлінгом ~25/с, надсилає
  текст/фото + кнопку застосунку (варіант `invite`). Обробка помилок:
  - `403` (bot blocked / user deactivated) → `isBlocked = true`, лічильник «заблоковано».
  - `429` → чекає `retry_after`, повторює цього користувача.
  - інше → лічильник «помилка», лог.
- Фінальний звіт адміну: всього / надіслано / заблоковано / помилок / тривалість.

Захист:
- Не дозволяти старт нової розсилки, поки виконується поточна.
- Якщо адмін замість контенту надсилає команду — чернетка скасовується.

### 6.4 Інтеграція з `telegram.service.ts`
За зразком делегування в `onboarding`/`foodInput`:
- Обробник `onText(/\/broadcast/)` → `broadcastService.start(chatId)`.
- Команда `/broadcast` **не** додається в `setMyCommands` (прихована від звичайних юзерів).
- Обробник `message` делегує контент у `BroadcastService`, коли той очікує ввід.
- Обробник `callback_query` роутить `broadcast:confirm` / `broadcast:cancel`.

### 6.5 Конфіг / константи
- `ADMIN_CHAT_ID` виноситься в env (fallback на наявну константу `7456685492`).
- URL-и застосунку та константа швидкості тротлінгу — у config/constants.

## 7. Крайові випадки

- **Фото:** беремо найбільший `file_id` з `msg.photo`; `sendPhoto` з caption + кнопкою.
- **Parse mode:** за замовчуванням простий текст (без `parse_mode`).
- **Event loop:** розсилка async з паузами — не блокує обслуговування інших юзерів.
- **Повернення заблокованого:** `/start` скидає `isBlocked`, і користувач знову
  потрапляє в аудиторію майбутніх розсилок.
- **Порожня аудиторія:** якщо активних 0 — бот повідомляє адміну й не запускає розсилку.

## 8. Тестування

`BroadcastService` (мок `bot` і `UserService`):
- класифікація помилок: `403` → позначка заблокованого; `429` → повтор;
- підрахунок фінального звіту (надіслано/заблоковано/помилок);
- фільтр аудиторії (`findActiveForBroadcast`).
- хелпер `appButton` — коректний URL і структура клавіатури.

Приклад стилю — наявний `src/telegram/telegram.service.spec.ts`.
